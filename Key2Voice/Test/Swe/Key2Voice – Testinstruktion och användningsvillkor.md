
# Key2Voice
## Testinstruktion och användningsvillkor

**Testversion – tidsbegränsad tillgång**

Tack för att du vill hjälpa oss att testa Key2Voice!

Key2Voice är en applikation som utvecklas för att förbättra tillgängligheten till talad information. Applikationen erbjuder bland annat taligenkänning och omvandling av tal till text.

Under testperioden får du möjlighet att prova Key2Voice med en tillfällig Premium-licens. Beroende på vilket testpaket du fått kan du även använda ett Azure Speech-testkonto som tillhandahålls av utvecklaren.

Läs igenom instruktionerna och villkoren innan du börjar.

---

# 1. Ditt testpaket

Ditt testpaket innehåller:

- En tidsbegränsad utvecklarlicens som ger tillgång till Key2Voice Premium.
- Konfiguration för Azure Speech.
- Information om testperiodens giltighet.

Testpaketet levereras som en krypterad synkfil med filändelsen `.k2s`.

# 2. Förberedelser

För att använda testpaketet behöver du:

- En kompatibel Windows-dator med Key2Voice installerat.
- En iPhone med Key2Voice installerat, om du ska testa iOS-versionen.
- Internetanslutning för funktioner som använder Azure Speech.
- Det testpaket och de instruktioner du fått från utvecklaren.

Om du redan använder Key2Voice rekommenderar vi att du säkerhetskopierar dina uppgifter innan du importerar ett testpaket.

# 3. Installera och aktivera testpaketet

### Steg 1 – Starta Key2Voice i Windows

Starta Key2Voice och öppna ditt befintliga valv, eller skapa ett nytt valv om du inte tidigare använt programmet.

### Steg 2 – Importera testpaketet

Öppna funktionen för synkimport.

Välj den `.k2s`-fil du fått och ange det lösenord som hör till filen.

Följ instruktionerna på skärmen.

Om programmet frågar hur befintliga uppgifter ska hanteras ska du följa de särskilda anvisningar som medföljer ditt testpaket.

### Steg 3 – Kontrollera aktiveringen

Kontrollera att Key2Voice visar att Premium-funktionerna är tillgängliga och att Azure Speech är konfigurerat.

### Steg 4 – Överför till iPhone

Om du ska testa iOS-versionen använder du Key2Voice synkfunktion för att överföra den aktuella konfigurationen till din iPhone.

Importera synkfilen i Key2Voice på iPhone.

Kontrollera därefter att Azure Speech är konfigurerat under **Om Key2Voice**.

**Observera:** En testlicens ger endast tillfällig tillgång till de funktioner och Azure-uppgifter som ingår i testet.

# 4. Under testperioden

Du får använda Key2Voice för att prova de funktioner som omfattas av testet.

Vi uppskattar särskilt återkoppling om:

- Hur väl taligenkänningen fungerar.
- Hur lätt applikationen är att använda.
- Eventuella fel, avbrott eller oväntade beteenden.
- Förslag på förbättringar.

Om du upptäcker ett problem får du gärna beskriva vad du gjorde när problemet uppstod och vilken enhet du använde.

Skicka inte lösenord, Azure-nycklar eller andra hemliga uppgifter i felrapporter.

# 5. Användning av Azure Speech

Key2Voice använder Microsoft Azure Speech för vissa funktioner.

Testpaketet kan innehålla autentiseringsuppgifter till ett Azure Speech-konto som utvecklaren tillhandahåller.

### När utvecklarens Azure-testkonto används

Du får använda kontot endast för att testa Key2Voice under den angivna testperioden.

Du får inte:

- Kopiera eller sprida kontots autentiseringsuppgifter.
- Använda kontot i andra applikationer eller tjänster.
- Använda kontot för automatiserad eller omfattande bearbetning som inte ingår i testet.
- Försöka kringgå testperiodens tidsbegränsning.

Utvecklaren kan begränsa eller avsluta tillgången till testkontot vid missbruk eller om det krävs av tekniska eller säkerhetsmässiga skäl.

### När du använder ett eget Azure-konto

Du kan även konfigurera Key2Voice med ett eget Azure Speech-konto i Windows.

Du ansvarar då själv för kontot, dess användning och eventuella kostnader enligt Microsofts villkor.

**Viktigt:** Att du använder ett eget Azure-konto innebär inte att du automatiskt får permanent rätt att använda Azure-konfigurationen i Key2Voice på iPhone.

Den rätten påverkas av hur konfigurationen överfördes och vilken Premium-licens som användes.

# 6. När testperioden upphör

Testlicensen gäller endast under den angivna perioden.

När den upphör gäller följande.

### Key2Voice för Windows

Om du inte har en egen Microsoft Store Premium-licens återgår Key2Voice till Basic.

Dina egna Azure Speech-uppgifter behålls i Windows-valvet.

Om du använder utvecklarens Azure-testkonto tas dess autentiseringsuppgifter bort när det tillhörande testpaketet har löpt ut.

Detta gäller även om du har köpt Microsoft Store Premium.

Dina övriga valvuppgifter behålls.

### Key2Voice för iPhone

När testperioden upphör tas utvecklarens Azure-testuppgifter bort från Key2Voice.

Om du har överfört ett eget Azure-konto till iPhone med hjälp av testlicensen kan även dessa uppgifter tas bort när testperioden upphör.

Detta gäller även om Azure-kontot tillhör dig.

Om du har en egen Microsoft Store Premium-licens och har överfört ditt eget Azure-konto genom en vanlig synkexport med verifierad Store Premium behålls däremot konfigurationen.

**Viktigt att känna till:**

Att Azure-uppgifterna tas bort innebär inte att ditt Azure-konto hos Microsoft avslutas.

Det är endast den lokalt sparade konfigurationen i Key2Voice som tas bort.

Sparade transkriptioner och övriga valvuppgifter påverkas inte.

# 7. Fortsätt använda Key2Voice efter testperioden

Om du vill fortsätta använda Key2Voice Premium efter testperioden kan du köpa Premium via Microsoft Store i Windows-versionen.

Om du använder ett eget Azure Speech-konto kan du därefter:

1. Kontrollera att Premium är aktiverat i Windows.
2. Konfigurera ditt eget Azure Speech-konto i Windows.
3. Skapa en ny, vanlig synkexport med Azure-uppgifterna.
4. Importera synkfilen i Key2Voice på iPhone.

Den nya konfigurationen kan då användas utan testpaketets tidsbegränsning.

**En köpt Premium-licens ger däremot aldrig fortsatt rätt att använda utvecklarens Azure-testkonto efter testperiodens slut.**

# 8. Integritet och personuppgifter

När du använder funktioner som bygger på Azure Speech kan ljud och talinformation skickas till Microsofts molntjänst för bearbetning.

Undvik att använda känsliga personuppgifter eller konfidentiell information under testningen om du inte har säkerställt att behandlingen är lämplig.

Microsofts villkor och integritetsinformation gäller för Azure Speech-tjänsten.

Utvecklaren får inte automatiskt tillgång till dina lokalt sparade transkriptioner enbart genom att du använder testpaketet.

Om du skickar loggar eller annan information till support bör du först kontrollera att de inte innehåller personuppgifter, lösenord eller andra hemligheter.

# 9. Testversion och ansvarsbegränsning

Key2Voice tillhandahålls under testperioden för utvärdering.

Programmet kan innehålla fel och funktioner kan förändras.

Du ansvarar för att säkerhetskopiera information som är viktig för dig.

Testversionen är inte avsedd att användas som enda informationskälla i situationer där felaktig eller utebliven taligenkänning kan medföra risk för personskada eller annan allvarlig skada.

Utvecklaren lämnar inga garantier om oavbruten tillgång till testtjänsterna.

Eventuella rättigheter enligt tvingande lag påverkas inte av dessa villkor.
