## **Key2Voice** – Speech to Text and Translation
Copyright 2026 Eureka Consulting AB

Key2Voice is an assistive tool that converts speech into readable text in real time. The Windows app can transcribe speech from a microphone, the computer's system audio, and WAV files. The **Subtitles** feature displays the latest transcribed text in a separate window with large text and automatic scrolling. You can also select languages for speech recognition and translation, and save, open, and edit transcripts.

The Windows app is available in two license tiers: **Basic** and **Premium**. Basic is free and includes speech recognition, translation, transcript management, and portable backup and restore. Premium also provides **Sync Export**, which lets you transfer configuration to Key2Voice for **iPhone** or export selected transcripts in an encrypted sync file. **Apple Watch** can be used together with iPhone.

Key2Voice uses **Microsoft Azure Speech** for speech recognition and translation. You need your own working Azure Speech account and an internet connection. Azure is a separate service that may incur charges; **Premium does not include an Azure subscription or Azure usage**. Therefore, test speech recognition with your own Azure Speech resource in Basic before purchasing Premium.
